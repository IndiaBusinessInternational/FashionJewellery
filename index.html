This app stores everything in your own Google Sheet through an Apps Script web app. Connect it once:

  1. Open Backend\IBIFashionJewellery_GAS.gs from the app folder on the laptop and paste it into a new project at script.google.com.
  2. Run fjSetup once and click Allow — it creates the Sheet and the Drive image folder.
  3. Project Settings → Script Properties → add OWNER_PIN.
  4. Deploy → New deployment → Web app → Execute as Me, access Anyone.
  5. Copy the /exec URL and paste it below.
